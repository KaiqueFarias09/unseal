# TIFF fixture provenance

The TIFF corpus has two sources: fixtures generated in this repository
(transcoded with the local libtiff tools) and real-world test images from the
MIT-licensed libtiff distribution. Every file's SHA-256 is listed below; the
decoders are verified against libtiff two ways — `tiffcmp -t` pixel parity at
development time (`dart run tool/tiff_fixtures.dart parity`, then `tiffcmp` per
page against a `tiffcp -c none` reference) and golden raster hashes pinned in
`test/tests/tiff/`.

## Generated fixtures

Deterministic source images are built by `tool/tiff_fixtures.dart` and
transcoded with libtiff 4.7.2's `tiffcp` (Homebrew). Regenerate with
`dart run tool/tiff_fixtures.dart generate`; the command is deterministic.

## Incidence notes

Codec incidence measured over this tracked corpus (15 real + 9 generated
fixtures): none (5 real, 3 generated), LZW (2 real + 1 compat), PackBits
(1 real + 1 generated), Deflate/AdobeDeflate (2 real + 1 generated), CCITT
Group 4 (2: one real, one generated), CCITT Group 3 (2: one real no-EOL, one
generated), JPEG-in-TIFF (2, both typed-unsupported), old-style JPEG (1,
typed-unsupported), palette (1, typed-unsupported), SGILOG (1,
typed-unsupported), planar=2 (1, typed-unsupported). BigTIFF: 1 generated.
Scanned-archive producers (the LoC/HABS-style corpus this wave targets) serve
Group 4 and LZW/none predominantly, which matches the supported set.

## Acquisition record

The design's preferred real-corpus source (Library of Congress free-to-use
sets) was attempted first on 2026-09-30: `tile.loc.gov` and `www.loc.gov`
both sit behind a Cloudflare browser challenge that returns HTTP 403 to
scripted downloads, so no LoC file could be acquired. The libtiff test-image
corpus was substituted: same permissive license, scriptable download, and it
carries real-world producer diversity (old-Compat LZW, no-EOL Group 3,
multi-IFD and sub-IFD chains, hostile IFD loops) that a single LoC scan would
not have covered. Multipage real coverage comes from `test_two_ifds.tif` and
`tiff_with_subifd_chain.tif`.

## Parity evidence

Development-time parity for every decodable fixture: `tiffcmp -t` against a
`tiffcp -c none` normalization of the same file, per page — all OK (2026-09-30,
libtiff 4.7.2), including the real Group 4 page (2453×3369), the real tiled
LZW pages, and the old-Compat LZW strips. CI pins the same evidence as golden
SHA-256 hashes of the decoded page images (see `test/tests/tiff/`) plus the
PBM/PGM/PPM pixel oracles for the real libtiff images.
